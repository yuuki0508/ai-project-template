# 仕様書と実装のズレを点検させる

```
docs/ 配下の仕様書と、現在の実装を突き合わせて、
矛盾している箇所を一覧にしてください。

観点:
- 仕様書にあるが実装されていない
- 実装されているが仕様書に無い
- 両方にあるが内容が違う
- docs/glossary.md と実際の識別子がずれている
- docs/decisions/ の決定に反している実装がある

出力は表形式で、各行に「箇所 / 仕様書の記述 / 実装 / どちらが正しいと思うか」を書いてください。
勝手に修正はしないでください。まず一覧だけ出してください。
```

節目（機能の実装完了時、納品前、しばらく触っていない案件の再開時）に流すと事故が減る。
