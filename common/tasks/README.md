# tasks

AIに作業させる単位を1ファイル1タスクで置く場所。

```
tasks/
├── _template.md
├── active/   … 作業中（同時に1〜2枚まで）
└── done/     … 完了したもの。過去の経緯として検索対象になる
```

## 使い方

1. `_template.md` をコピーして `active/T-001-画面追加.md` のように作る
2. 目的・触ってよいファイル・完了条件を埋める（ここが雑だとAIが暴走する）
3. AIに「`tasks/active/T-001-画面追加.md` に従って進めて」と指示する
4. 終わったら作業ログを書かせて `done/` へ移動する

## なぜファイルにするのか

チャットに書いた指示はセッションが切れると消える。ファイルに置けば、
別のセッションでも別のツール（Cursor / Claude Code）でも同じ前提で再開できる。
